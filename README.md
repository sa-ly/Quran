# Quran - موقع القرآن الكريم الشامل

حزمة موقع كاملة مهيأة للنشر الفوري والمجاني عبر **GitHub Pages**.

## محتويات الحزمة:
- `index.html`: الصفحة الرئيسية المشتملة على محرك البحث السريع وفهرس الـ 114 سورة.
- `al-fatihah.html` ... `an-nas.html`: صفحات مستقلة لكل سورة مع مشغل الصوت والنص القرآني الكامل.
- `sitemap.xml`: خريطة الموقع لمحركات البحث جوجل.
- `robots.txt` و `404.html` و `.nojekyll`.

## خطوات النشر والتشغيل على GitHub Pages:
1. افتح مستودعك على GitHub: https://github.com/sa-ly/Quran
2. إذا كانت هناك ملفات قديمة بها تعارض، احذفها أو ارفع ملفات هذا الأرشيف بعد فك ضغطه (تأكد من وجود `index.html` والملفات بصيغة `*.html`).
3. ادخل إلى **Settings** > **Pages** > تأكد أن المصدر هو **Deploy from a branch** وفرع **main** ومجلد **/(root)**.
4. انتظر دقيقة واحدة وستظهر الصفحة الرئيسية على رابط: https://sa-ly.github.io/Quran/
