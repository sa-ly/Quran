# Quran - موقع القرآن الكريم الشامل

حزمة موقع كاملة مهيأة للنشر الفوري والمجاني عبر **GitHub Pages**.

## محتويات الحزمة:
- `index.html`: الصفحة الرئيسية ومحرك البحث السريع وفهرس الـ 114 سورة.
- `al-fatihah/index.html` ...: صفحات مستقلة لكل سورة بروابط نقية فائقة السرعة.
- `sitemap.xml`: خريطة الموقع لمحركات البحث جوجل.
- `CNAME`: ربط النطاق المخصص (sa-ly.github.io).
- `robots.txt` و `404.html`.

## خطوات النشر في دقيقتين:
1. افتح حسابك على GitHub وأنشئ مستودعاً جديداً (New Repository) عاماً (Public).
2. فك ضغط هذا الأرشيف وارفع جميع الملفات مباشرة إلى المستودع.
3. ادخل إلى **Settings** > **Pages** > اختر **Deploy from a branch** وحدد **main** واضغط **Save**.
4. سيعمل موقعك فوراً مع شهادة أمان SSL مجانية وسرعة فائقة بدون أي تكلفة!
